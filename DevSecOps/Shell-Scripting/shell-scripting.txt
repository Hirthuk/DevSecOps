| Operator | Meaning                                                  | Example                             | Explanation                                                  |
| -------- | -------------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------ |
| `<`      | Takes input **from a file**                              | `wc -w < hello.txt`                 | Sends the contents of `hello.txt` as input to `wc`.          |
| `<<`     | **Heredoc (multiple lines)** input until a **delimiter** | `cat << EOD Hello World Line 2 EOD` | Sends multiple lines as input to `cat` until it reads `EOD`. |
| `<<<`    | **Herestring (single line)** input                       | `cat <<< "Hello World"`             | Sends a **single line** string as input to the command.      |

### 🧠 **AWK – Text Processing Tool**

* Used for **extracting**, **filtering**, and **analyzing** text (line by line).
* Works with **fields/columns**.

**Syntax:**

```bash
awk 'pattern { action }' file
```

**Common uses:**

* `awk '{print $1}' file` → print 1st column
* `awk -F: '{print $1}' /etc/passwd` → custom separator `:`
* `awk '/error/ {print}' log.txt` → print lines with “error”
* `awk '$3 > 100 {print $1, $3}' data.txt` → condition

**Special vars:**
`$0` (whole line), `$1,$2…` (fields), `NR` (line no), `NF` (no. of fields)

---

### 🧰 **SED – Stream Editor**

* Used for **find**, **replace**, or **delete** text in files.

**Syntax:**

```bash
sed 'command' file
```

**Common uses:**

* `sed 's/foo/bar/' file` → replace first “foo”
* `sed 's/foo/bar/g' file` → replace all “foo”
* `sed -i 's/dev/prod/g' app.conf` → replace in file
* `sed '/error/d' file` → delete lines with “error”
* `sed -n '3p' file` → print line 3

---

### ⚙️ **Quick Difference**

| Task                   | Tool     |
| ---------------------- | -------- |
| Extract columns        | 🟢 `awk` |
| Replace text           | 🟢 `sed` |
| Conditional logic      | 🟢 `awk` |
| Delete or modify lines | 🟢 `sed` |

---

✅ **Examples**
